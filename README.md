Starter Pack

## Project Overview

This repository contains my personal Full-Stack Starter Pack — a reusable foundation for building future web applications

The goal is to avoid rebuilding the same infrastructure for every project and focus more on product development, business logic, and delivering real-world applications.

This Starter Pack will serve as the starting point for my upcoming projects

## Core Technologies

### Frontend
- React.js
- JavaScript
- Vite
- React Router
- TanStack React Query
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)

## Implemented Features

- Feature-Based Frontend Architecture
- Modular Backend Architecture
- OTP-Based Authentication
- JWT Authentication
- HTTP-Only Cookie-Based Token Storage
- Authentication Middleware
- Token Versioning for Session Revocation
- React Query for Server State Management
- Centralized API Configuration with Axios
- Protected Routes
- Public Routes
- Guest and Authenticated User Handling
- Global Query Client and Providers
- Centralized Exception Handling

## Architecture Goals

- Reusable project structure
- Separation of concerns
- Maintainable and scalable codebase
- Consistent authentication flow
- Reusable frontend and backend modules
- Avoiding unnecessary complexity and over-engineering

## Development Philosophy

Build once, reuse across projects, and improve continuously.

This Starter Pack is not intended to be a universal framework. It is a practical foundation that will evolve based on real project requirements.

Every new project should reuse the parts that make sense and extend them when necessary.
